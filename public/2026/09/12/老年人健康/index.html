记忆力下降

上年纪记忆力下降，先别急着买“补脑药”。多数情况下，食补+动补+睡补+社交补比单纯吃补剂更管用；但也要先排除可逆原因。

1. 先查一查，别把病当“老了” 如果记忆力下降明显、影响生活，建议去神经内科/记忆门诊。常查：血常规、维生素B12、叶酸、同型半胱氨酸、甲状腺功能、血糖/糖化、肝肾功能、维生素D等。还要看有没有抑郁焦虑、睡眠呼吸暂停、听力下降，以及是否吃了安眠药、抗过敏药等影响记忆的药。这些纠正后，记忆可能改善。

2. 吃：接近“MIND饮食/地中海饮食”

  • 每天：深色蔬菜、全谷物、豆类、坚果、橄榄油；适量水果，尤其蓝莓、草莓等浆果。
  • 每周：鱼2—3次，优先三文鱼、沙丁鱼、鲭鱼；鸡蛋、禽肉适量。
  • 少吃：红肉、黄油、奶酪、甜食、油炸、加工食品、过咸食物。
  • 可常吃：核桃、亚麻籽、鸡蛋、大豆制品、菠菜、西兰花、燕麦、糙米。
  • 水要喝够，便秘也会影响状态。

3. 补剂：缺才补，不缺不补

  • 维生素B12：老人、素食、长期吃抑酸药的人容易缺。查血后缺再补，甲钴胺/氰钴胺常见。
  • 叶酸+B6+B12：同型半胱氨酸高的人，医生可能建议补。
  • 维生素D：很多老人不足，可查血后补，常与钙一起考虑。
  • Omega-3鱼油：证据不算强，看EPA+DHA含量；吃抗凝药者要问医生。
  • 银杏、磷脂酰丝氨酸、NAD+、PQQ等：证据有限，别花冤枉钱；银杏与抗凝药同用有出血风险。 一句话：先食补，缺啥补啥，别自行大剂量长期吃。

4. 比补剂更重要的“补脑法”

  • 运动：每周150分钟快走、游泳等有氧，加2次力量训练。证据最强。
  • 睡眠：7—8小时，打鼾严重、白天嗜睡要查睡眠呼吸暂停。
  • 社交：多聊天、参加活动、志愿服务，别独居闷着。
  • 用脑：学新技能、乐器、外语、棋牌、阅读，比重复做简单题更好。
  • 记忆辅助：固定放钥匙、写清单、用日历提醒，减少焦虑。
  • 控三高：血压、血糖、血脂、体重管理好，戒烟限酒。
  • 矫正听力视力：听不清会加速认知下降。

5. 什么时候必须就医 突然变糊涂、几周内明显加重、迷路、算错账、重复问同一句话、性格改变、幻觉、影响吃药做饭，尽快就医。若确诊阿尔茨海默病等，医生会用药，如多奈哌齐、美金刚等，但必须处方，不能靠保健品逆转。

简单总结：先查因；每天吃好、走够、睡足、多社交；补剂只补缺的。若只是偶尔忘事，按这套做；若影响生活，尽早去记忆门诊。

下面按你刚才的模板，把老年人常见的其他问题也分类列出来。还是先说一句：很多“老了就这样”的表现，其实可能是可逆的病，先查再调，别硬扛。

一、行动/腿脚问题

1. 先查一查，别把病当“老了” 如果走路变慢、腿沉、容易摔，建议去骨科/神经内科/老年科。常查：骨密度、维生素D、血钙、肌酶、甲状腺功能、血糖、颈椎/腰椎影像、下肢血管超声。还要看有没有帕金森、脑梗后遗症、关节炎、腰椎管狭窄、周围神经病变。

2. 吃：保肌肉、保骨头

  • 每天：牛奶/酸奶、鸡蛋、豆制品、深色蔬菜。
  • 每周：鱼2—3次，瘦肉适量。
  • 重点补：蛋白质（每餐都要有）、钙、维生素D。
  • 少吃：过咸、过甜、油炸，影响钙吸收和血管。

3. 补剂：缺才补

  • 维生素D+钙：老人常见不足，查血后补。
  • 蛋白质粉：吃不够肉蛋奶时可考虑。
  • 氨糖/软骨素：证据有限，别当神药。
  • 胶原蛋白：吃进去会分解，不如直接吃够蛋白质。

4. 比补剂更重要的“补腿法”

  • 运动：快走、太极、八段锦，加力量训练（弹力带、靠墙静蹲）。
  • 平衡：单脚站、脚跟走、脚尖走，扶稳再练。
  • 防摔：家里防滑垫、夜灯、扶手，穿合脚鞋。
  • 控三高：血压血糖血脂管好，戒烟限酒。
  • 矫正视力：看不清更容易摔。

5. 什么时候必须就医 突然腿软、走不了、大小便失控、摔倒后剧痛、单侧无力，尽快就医。

二、睡眠问题

1. 先查一查 去睡眠门诊/神经内科/呼吸科。常查：睡眠呼吸监测、甲状腺功能、血糖、抑郁焦虑量表。看是否吃安眠药、抗过敏药、利尿剂。

2. 吃：助眠不靠酒

  • 晚餐：清淡、七分饱，睡前3小时不进食。
  • 可喝：温牛奶、小米粥。
  • 少吃：咖啡、浓茶、酒、辛辣、油腻。
  • 白天：晒太阳，帮助夜间褪黑素分泌。

3. 补剂：缺才补

  • 褪黑素：倒时差或入睡困难可短期小剂量，别长期大剂量。
  • 镁：缺镁可能影响睡眠，查血后补。
  • GABA、缬草、酸枣仁：证据有限，别替代药物。

4. 比补剂更重要的“补睡法”

  • 固定作息：每天同一时间睡、起。
  • 睡前：关灯、关手机、泡脚、听轻音乐。
  • 白天：午睡不超过30分钟，下午3点后不睡。
  • 运动：白天运动，睡前3小时不剧烈运动。
  • 打鼾严重、憋醒：查睡眠呼吸暂停。

5. 什么时候必须就医 长期失眠、白天嗜睡、打鼾憋醒、梦游、腿不安，尽快就医。

三、情绪/心理问题

1. 先查一查 去精神心理科/老年科。常查：抑郁焦虑量表、甲状腺功能、维生素B12、叶酸、血糖。看是否吃降压药、激素、安眠药。

2. 吃：情绪也靠营养

  • 每天：全谷物、豆类、坚果、深色蔬菜。
  • 每周：鱼2—3次，富含Omega-3。
  • 少吃：高糖、高油、加工食品。
  • 少喝酒：酒会加重抑郁焦虑。

3. 补剂：缺才补

  • 维生素B12、叶酸、维生素D：缺了可能影响情绪。
  • Omega-3：证据中等，可适量。
  • 圣约翰草：与很多药冲突，别自行吃。

4. 比补剂更重要的“补心法”

  • 社交：多聊天、参加活动、志愿服务。
  • 运动：每天快走30分钟，抗抑郁效果不输药。
  • 倾诉：找家人朋友说，别憋着。
  • 爱好：养花、书法、唱歌、跳舞。
  • 晒太阳：每天15—30分钟。

5. 什么时候必须就医 持续两周以上情绪低落、不想动、睡不着、吃不下、有轻生念头，尽快就医。

四、听力/视力问题

1. 先查一查 去耳鼻喉科/眼科。常查：听力测试、眼底、眼压、血糖、血压。看是否吃耳毒性药物。

2. 吃：护耳护眼

  • 每天：深色蔬菜、蓝莓、胡萝卜、玉米、蛋黄。
  • 每周：鱼2—3次。
  • 少吃：高糖、高油、过咸。
  • 戒烟限酒：烟酒伤血管，也伤耳眼。

3. 补剂：缺才补

  • 叶黄素、玉米黄质：黄斑变性可考虑。
  • 维生素A：缺才补，过量中毒。
  • 锌、硒：缺才补。
  • Omega-3：证据中等。

4. 比补剂更重要的“补耳眼法”

  • 听力：戴助听器，别硬扛，听不清加速认知下降。
  • 视力：配老花镜、白内障手术，别拖。
  • 护眼：少看手机，多远眺，防紫外线。
  • 护耳：远离噪音，别乱掏耳朵。
  • 控三高：糖尿病视网膜病变、高血压眼底病变要控好。

5. 什么时候必须就医 突然耳聋、耳鸣加重、视力骤降、眼前黑影、眼痛，尽快就医。

五、便秘/消化问题

1. 先查一查 去消化科/老年科。常查：肠镜、便潜血、甲状腺功能、血糖、电解质。看是否吃钙片、铁剂、止痛药。

2. 吃：通便靠纤维和水

  • 每天：蔬菜、水果、全谷物、豆类。
  • 可吃：火龙果、猕猴桃、西梅、燕麦、红薯。
  • 多喝水：每天1500—2000毫升，心肾疾病遵医嘱。
  • 少吃：精细米面、油炸、辛辣。
  • 适量油：橄榄油、亚麻籽油。

3. 补剂：缺才补

  • 膳食纤维粉：吃不够菜时可考虑。
  • 益生菌：证据有限，可试。
  • 镁：缺镁可能便秘，查血后补。
  • 乳果糖、聚乙二醇：医生指导下用，别长期靠泻药。

4. 比补剂更重要的“通便法”

  • 运动：每天走30分钟，揉肚子。
  • 排便：固定时间，别憋。
  • 姿势：脚下垫小凳，别久蹲。
  • 情绪：焦虑也便秘。

5. 什么时候必须就医 便血、黑便、消瘦、腹痛、便秘腹泻交替，尽快就医。

六、免疫力/易感冒问题

1. 先查一查 去老年科/免疫科。常查：血常规、免疫球蛋白、维生素D、血糖、肝肾功能。看是否吃激素、免疫抑制剂。

2. 吃：免疫靠蛋白质和微量营养素

  • 每天：鸡蛋、牛奶、豆制品、瘦肉、深色蔬菜。
  • 每周：鱼2—3次，菌菇类。
  • 少吃：高糖、高油、加工食品。
  • 多喝水：别等渴了才喝。

3. 补剂：缺才补

  • 维生素D：老人常见不足。
  • 维生素C、锌：缺才补，过量不好。
  • 蛋白质粉：吃不够时考虑。
  • 益生菌：证据有限。

4. 比补剂更重要的“补免疫法”

  • 运动：每周150分钟中等强度。
  • 睡眠：7—8小时。
  • 疫苗：流感、肺炎、带状疱疹疫苗，问医生。
  • 洗手：勤洗手，少去人多密闭场所。
  • 控三高：血糖高易感染。

5. 什么时候必须就医 反复发烧、感染难好、体重骤降、淋巴结肿大，尽快就医。

七、皮肤/瘙痒问题

1. 先查一查 去皮肤科/老年科。常查：血糖、肝肾功能、甲状腺功能、过敏原。看是否吃降压药、降糖药。

2. 吃：护皮肤

  • 每天：深色蔬菜、坚果、鱼。
  • 多喝水：皮肤不干。
  • 少吃：辛辣、酒、高糖。
  • 适量油：橄榄油、亚麻籽油。

3. 补剂：缺才补

  • 维生素D、Omega-3：可能有益。
  • 维生素A、E：缺才补，过量中毒。
  • 胶原蛋白：证据有限。

4. 比补剂更重要的“护肤法”

  • 洗澡：水温别太高，少用肥皂。
  • 保湿：洗完涂润肤霜。
  • 穿衣：纯棉、宽松。
  • 防晒：出门防晒。
  • 控血糖：糖尿病易痒。

5. 什么时候必须就医 皮疹不愈、溃烂、出血、剧痒影响睡眠，尽快就医。

下面把上一次补充的十二类问题，按之前那个详细模板完整展开。你可以直接接着前面的清单用。

九、血压/血糖/血脂不稳

1. 先查一查 去心内科/内分泌科/老年科。常查：血压、空腹血糖、糖化血红蛋白、血脂四项、肝肾功能、尿微量白蛋白、心电图。看是否吃降压药、降糖药、激素、止痛药。

2. 吃：少盐少糖少油

  • 每天：深色菜、全谷物、豆类、菌菇。
  • 每周：鱼2—3次，蛋、奶、瘦肉适量。
  • 少吃：咸菜、腊肉、甜饮料、蛋糕、油炸、肥肉。
  • 多喝水：别等渴了才喝。
  • 戒烟限酒：酒少喝，烟戒掉。

3. 补剂：缺才补

  • 钾、镁：缺才补，肾功能不好要问医生。
  • 维生素D：老人常不足，查血后补。
  • Omega-3鱼油：证据中等，吃抗凝药要问医生。
  • 别信“降三高保健品”：不能代替药。

4. 比补剂更重要的“稳三高法”

  • 每天量血压，按医嘱吃药，别自己停。
  • 血糖高：定时定量吃饭，少稀饭、少甜食。
  • 血脂高：多鱼少肉，多蒸煮少油炸。
  • 运动：每周150分钟快走，加力量训练。
  • 控体重：腰围别太粗。
  • 睡好、少生气：情绪也会升血压血糖。

5. 什么时候必须就医 头晕、胸闷、心慌、血糖过高过低、血压突然很高、说话不清、单侧无力，尽快就医。

十、夜尿多、尿频、漏尿

1. 先查一查 去泌尿科/肾内科/妇科。常查：尿常规、肾功能、血糖、前列腺/妇科超声、残余尿。看是否吃利尿剂、降压药。

2. 吃：晚饭少汤水

  • 白天喝够水，睡前2小时少喝水。
  • 少咖啡、浓茶、酒、辛辣。
  • 少吃：过咸、过甜、利尿食物。
  • 多吃：蔬菜、全谷物、豆类，防便秘。

3. 补剂：缺才补

  • 维生素D、钙：缺才补。
  • 别乱吃“补肾药”：可能伤肾。
  • 蔓越莓：证据有限，别当药。

4. 比补剂更重要的“护尿法”

  • 练提肛：每天多次，每次收缩3—5秒。
  • 别憋尿，也别频繁跑厕所。
  • 防便秘：便秘会加重漏尿。
  • 控体重、控血糖。
  • 晚上少喝汤水，睡前排空尿。
  • 男的查前列腺，女的查盆底。

5. 什么时候必须就医 尿痛、尿血、尿不出、突然漏尿加重、发热腰痛，尽快就医。

十一、骨头脆、腰背痛、身高变矮

1. 先查一查 去骨科/内分泌科，查骨密度。常查：血钙、磷、维生素D、甲状旁腺激素、肾功能。看是否吃激素、抑酸药。

2. 吃：补钙补蛋白

  • 每天：奶、酸奶、豆制品、深色菜。
  • 每周：鱼2—3次，蛋、瘦肉适量。
  • 少吃：过咸、过甜、咖啡、浓茶、酒。
  • 多晒太阳：每天15—30分钟。

3. 补剂：缺才补

  • 钙：缺才补，过量可能结石。
  • 维生素D：老人常不足，查血后补。
  • 蛋白质粉：吃不够肉蛋奶时可考虑。
  • 胶原蛋白：证据有限，不如吃够蛋白。

4. 比补剂更重要的“护骨法”

  • 运动：快走、太极、弹力带、靠墙静蹲。
  • 防摔：防滑垫、夜灯、扶手、合脚鞋。
  • 控三高、戒烟限酒。
  • 别长期躺，越躺骨越脆。

5. 什么时候必须就医 轻轻一摔就骨折、腰背剧痛、身高明显变矮、驼背加重，尽快就医。

十二、吃药太多、吃错药

1. 先查一查 去老年科/药学门诊，做“用药梳理”。常查：肝肾功能、电解质、血常规、凝血。看是否重复用药、药物相互作用。

2. 吃：别自己加停换

  • 别自己加药、停药、换药。
  • 少吃保健品，补剂也要问医生。
  • 吃药别用酒、茶、牛奶送服，除非医生允许。
  • 饭前饭后按医嘱，别搞混。

3. 补剂：缺才补

  • 补剂也要问医生，避免和药冲突。
  • 银杏、圣约翰草、鱼油：可能和抗凝药冲突。
  • 钙、铁：可能影响某些药吸收。

4. 比补剂更重要的“管药法”

  • 写用药清单：药名、剂量、时间。
  • 用分药盒，设闹钟。
  • 定期整理药箱，过期药扔掉。
  • 看不同科，主动说“我在吃什么药”。
  • 家人帮忙核对。

5. 什么时候必须就医 头晕、乏力、出血、意识模糊、突然跌倒，尽快就医。

十三、吞咽呛咳、吃饭费劲

1. 先查一查 去耳鼻喉科/神经内科/康复科。常查：吞咽功能评估、头颅CT/MRI、喉镜。看是否脑梗后遗症、帕金森、食管问题。

2. 吃：软烂、小块、慢吃

  • 软烂：粥、蒸蛋、豆腐、鱼肉泥、菜泥。
  • 少干硬、少黏食、少颗粒。
  • 少辛辣、少过烫。
  • 吃不够时用营养粉，问医生。

3. 补剂：缺才补

  • 蛋白质粉：吃不够时考虑。
  • 维生素D、B12：缺才补。
  • 增稠剂：喝水呛咳时，医生可能建议。

4. 比补剂更重要的“防呛法”

  • 坐直吃，别躺着吃。
  • 别边说边吃，小口慢咽。
  • 饭后别马上躺，坐30分钟。
  • 假牙要合，牙不好要修。
  • 康复训练：练吞咽、练口唇。

5. 什么时候必须就医 反复呛咳、发烧、体重下降、吃不下、说话不清，尽快就医。

十四、牙齿不好、口干

1. 先查一查 去口腔科。常查：牙周、龋齿、假牙、口腔黏膜。看是否吃降压药、抗抑郁药、抗过敏药。

2. 吃：软烂、清淡、多水

  • 软烂：粥、蒸蛋、豆腐、鱼肉、菜泥。
  • 多喝水，少量多次。
  • 少甜、少黏、少辛辣。
  • 多吃：奶、豆、深色菜。

3. 补剂：缺才补

  • 维生素D、钙：缺才补。
  • 维生素C：缺才补。
  • 人工唾液：口干严重可问医生。

4. 比补剂更重要的“护牙法”

  • 早晚刷牙，饭后漱口。
  • 假牙每天洗，晚上取下。
  • 定期看牙，半年到一年一次。
  • 牙不好早修，别硬扛。
  • 口干多喝水，少含糖。

5. 什么时候必须就医 牙痛、牙龈出血、口腔溃疡不愈、假牙不合、吃不下，尽快就医。

十五、头晕、耳鸣、平衡差

1. 先查一查 去神经内科/耳鼻喉科/心内科。常查：血压、血糖、血脂、颈椎、头颅CT/MRI、听力。看是否吃降压药、安眠药。

2. 吃：清淡、少盐、多水

  • 少盐、少油、少糖。
  • 多喝水，别脱水。
  • 少咖啡、浓茶、酒。
  • 多吃：深色菜、全谷物、豆、鱼。

3. 补剂：缺才补

  • 维生素B12、维生素D：缺才补。
  • 镁：缺才补。
  • 银杏：证据有限，吃抗凝药要问医生。

4. 比补剂更重要的“防晕法”

  • 起床慢：躺30秒、坐30秒、站30秒。
  • 转身慢，别猛回头。
  • 扶稳，用拐杖/助行器。
  • 练平衡：单脚站、脚跟走。
  • 控三高，戒烟限酒。

5. 什么时候必须就医 突然眩晕、说话不清、单侧无力、走路偏斜、视物重影，尽快就医。

十六、体重突然下降或肥胖

1. 先查一查 去老年科/内分泌科/消化科。常查：血常规、血糖、甲状腺功能、肝肾功能、肿瘤标志物、胃肠镜。看是否吃影响体重的药。

2. 吃：瘦了加营养，胖了减油糖

  • 瘦了：蛋、奶、豆、鱼、肉、坚果，少量多餐。
  • 胖了：少油、少糖、少精米白面，多菜多全谷。
  • 多喝水，少甜饮料。
  • 戒烟限酒。

3. 补剂：缺才补

  • 蛋白质粉：吃不够时考虑。
  • 维生素D、B12：缺才补。
  • 别乱吃减肥药：伤身。

4. 比补剂更重要的“控重法”

  • 每周称体重，记录。
  • 瘦了要查因，别高兴太早。
  • 胖了要运动：快走、游泳、力量训练。
  • 睡好、少压力。
  • 家人帮忙记录饮食。

5. 什么时候必须就医 半年瘦5%以上、吃不下、腹痛、便血、体重骤增伴水肿，尽快就医。

十七、孤独、不想出门

1. 先查一查 去老年科/心理科/社区活动中心。常查：抑郁焦虑量表、甲状腺功能、维生素B12、叶酸。看是否独居、丧偶、听力下降。

2. 吃：规律三餐，别凑合

  • 每天：蛋、奶、豆、谷物、深色菜、水果。
  • 每周：鱼2—3次，菌菇。
  • 少吃：咸菜、剩饭、甜食。
  • 多喝水。

3. 补剂：缺才补

  • 维生素B12、叶酸、维生素D：缺才补。
  • Omega-3：证据中等。
  • 圣约翰草：和很多药冲突，别自行吃。

4. 比补剂更重要的“补心法”

  • 每天出门一次，晒太阳。
  • 多打电话、多聊天。
  • 参加社区活动、志愿服务。
  • 养花、养宠物、唱歌、跳舞。
  • 家人常回家看看。
  • 听不清就戴助听器。

5. 什么时候必须就医 长期不出门、不吃不喝、情绪极差、有轻生念头，尽快就医。

十八、跌倒后怕再摔、不敢走

1. 先查一查 去康复科/骨科/老年科。常查：骨密度、肌力、平衡、步态、视力、听力。看是否吃安眠药、降压药。

2. 吃：保肌肉

  • 每天：蛋、奶、豆、瘦肉、深色菜。
  • 每周：鱼2—3次。
  • 少吃：过咸、过甜、油炸。
  • 多喝水。

3. 补剂：缺才补

  • 钙、维生素D：缺才补。
  • 蛋白质粉：吃不够时考虑。
  • 别乱吃“壮骨保健品”。

4. 比补剂更重要的“敢走法”

  • 康复训练：平衡、力量、步态。
  • 用拐杖/助行器，别怕丢人。
  • 家里防滑、夜灯、扶手。
  • 穿合脚鞋，别穿拖鞋。
  • 家人陪同，慢慢练。
  • 越不敢走，越走不了。

5. 什么时候必须就医 越走越差、腿无力、疼痛、不敢站、摔倒后剧痛，尽快就医。

十九、皮肤伤口不愈、脚烂

1. 先查一查 去内分泌科/血管外科/皮肤科。常查：血糖、糖化、下肢血管超声、神经病变、感染指标。看是否吃激素、免疫抑制剂。

2. 吃：控糖补蛋白

  • 每天：蛋、奶、豆、鱼、瘦肉、深色菜。
  • 少吃：高糖、高油、过咸。
  • 多喝水。
  • 戒烟限酒。

3. 补剂：缺才补

  • 维生素C、锌、维生素D：缺才补。
  • 蛋白质粉：吃不够时考虑。
  • 别乱涂偏方。

4. 比补剂更重要的“护脚法”

  • 每天看脚，包括脚底、脚趾缝。
  • 保持干燥，穿合脚鞋、棉袜。
  • 别自己剪硬皮、修鸡眼。
  • 控血糖、控血压、控血脂。
  • 戒烟：烟伤血管，伤口更难好。

5. 什么时候必须就医 伤口不愈、发黑、流脓、脚麻脚冷、发热，尽快就医。

二十、记不住吃药、忘关火、忘带钥匙

1. 先查一查 去神经内科/记忆门诊。常查：认知评估、头颅MRI、维生素B12、叶酸、甲状腺功能、血糖。看是否吃安眠药、抗过敏药。

2. 吃：同记忆力下降

  • 深色菜、全谷物、豆、坚果、鱼、浆果。
  • 少吃：高糖、高油、加工食品。
  • 多喝水。

3. 补剂：缺才补

  • 维生素B12、叶酸、维生素D：缺才补。
  • Omega-3：证据中等。
  • 银杏、NAD+等：证据有限，别花冤枉钱。

4. 比补剂更重要的“防忘法”

  • 分药盒、设闹钟。
  • 固定放钥匙、眼镜、钱包。
  • 出门检查清单：钥匙、手机、火、水、电。
  • 用日历、便签提醒。
  • 家人帮忙核对。
  • 学新东西、多社交、多运动。

5. 什么时候必须就医 忘关火、忘吃药、迷路、重复问话、算错账、性格改变，尽快就医。

总结一句话

老年人常见问题，基本都遵循这个模板：

先查因 → 食补 → 缺才补剂 → 运动/睡眠/社交/控三高 → 影响生活尽早就医。

□ 1. 三高不稳，脑子、腿脚、眼睛、肾都遭殃。
□ 2. 夜尿多、漏尿、呛咳，别忍，能治。
□ 3. 吃药太多要梳理，别自己加停换。
□ 4. 牙不好、吃不下，会越来越瘦、越来越弱。
□ 5. 孤独不出门，比很多病更伤身。
