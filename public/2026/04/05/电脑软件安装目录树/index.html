📁 D:\
│
├─📁 00_SystemCache          # 系统/软件缓存目录（设快捷方式，平时不常开）
│
├─📁 01_Code_Projects         # 所有代码项目
│   ├─📁 GitHub_Repos          # Git克隆的第三方库
│   ├─📁 Work                  # 公司项目
│   │   ├─📁 Project_A
│   │   └─📁 Project_B
│   ├─📁 Personal              # 个人项目/练手
│   ├─📁 Sandbox               # 临时测试代码（随时可删）
│   └─📁 Libraries             # 本地依赖包（如maven/node_modules备份）
│
├─📁 02_IDE_Tools              # 开发工具绿色版/配置
│   ├─📁 IntelliJ_IDEA
│   ├─📁 VSCode
│   ├─📁 Postman
│   ├─📁 Git
│   ├─📁 Docker_Data           # 容器持久化数据
│   └─📁 VirtualMachines       # 虚拟机磁盘文件
│
├─📁 03_Database               # 数据库相关
│   ├─📁 MySQL_Data
│   ├─📁 PostgreSQL_Data
│   ├─📁 MongoDB_Data
│   ├─📁 Redis_Data
│   └─📁 Backups_SQL           # SQL导出文件
│
├─📁 04_Documents              # 个人文档/笔记（根目录）
│   ├─📁 Books_PDF             # 可迁移到 05_Reading，或保留作为备用
│   ├─📁 Tech_Blogs            # 下载的优质博文/离线文档
│   ├─📁 Diagrams              # 架构图/流程图源文件（draw.io/uml）
│   ├─📁 Interview             # 面试题/简历
│   └─📁 Logs                  # 自己程序的日志输出（集中管理）
│
├─📁 05_Reading                # 🆕 个人阅读目录（书籍/文章/资料）
│   ├─📁 Programming           # 编程技术书
│   ├─📁 ComputerScience       # 计算机基础（OS/网络/组成原理）
│   ├─📁 SoftSkills            # 软技能/职场/管理
│   ├─📁 Math_Physics          # 数学/物理
│   ├─📁 Humanities            # 人文/历史/心理
│   ├─📁 ToRead                # 待读队列
│   └─📁 Articles_Archive      # 保存的优质长文/PDF论文
│
├─📁 06_Notes                  # 🆕 个人笔记目录（自己写的笔记/日记/脑图）
│   ├─📁 Tech_Notes            # 技术学习笔记（分语言/框架）
│   │   ├─📁 Golang
│   │   ├─📁 Python
│   │   ├─📁 Rust
│   │   ├─📁 Docker_K8s
│   │   └─📁 Database
│   ├─📁 Work_Logs             # 工作日志/周报/复盘
│   ├─📁 Ideas                 # 灵感/草稿/待办项目
│   ├─📁 MindMaps              # XMind/.drawio 源文件
│   ├─📁 Summaries             # 读书/课程/会议总结
│   └─📁 Journal               # 个人日记（可选，加密存放）
│
├─📁 07_Media_Resources        # 素材/非代码文件（原05改为07）
│   ├─📁 Icons_UI              # 图标/UI素材
│   ├─📁 Wallpapers
│   ├─📁 Video_Tutorials       # 教学视频
│   └─📁 Music_Work            # 工作背景音乐
│
├─📁 08_DevOps                 # 运维/脚本/环境（原06改为08）
│   ├─📁 Scripts               # .bat/.ps1/.sh 脚本
│   ├─📁 Docker_Compose        # 编排文件
│   ├─📁 Kubernetes            # yaml配置
│   └─📁 Terraform             # IaC
│
├─📁 09_Backup                 # 重要文件归档（原07改为09）
│   ├─📁 dotfiles              # .vimrc, .bashrc 等
│   ├─📁 License_Keys
│   └─📁 Old_Projects_Archive  # 已结项的老项目压缩包
│
└─📁 99_Temp                   # 临时文件（定期清空）
    ├─📁 Downloads
    ├─📁 Unzip
    └─📁 Screenshots
