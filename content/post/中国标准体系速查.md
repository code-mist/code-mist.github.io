# 中国标准体系一图流：GB / Q / T / DB / JB 到底谁管谁

> 一篇写给「看包装、看检测报告、写招投标文件」的人的长期笔记。
> 核心一句话：**代号看层级，斜杠看强制还是推荐，年份看版本，顺序号看是哪一份。**

---

## 0. 先背这张总表（全篇的地图）

| 层级     | 代号                                  | 全称                        | 性质     | 谁发布                     | 典型例子                   | 效力                          |
| -------- | ------------------------------------- | --------------------------- | -------- | -------------------------- | -------------------------- | ----------------------------- |
| 国家标准 | **GB**                                | 强制性国家标准              | 强制     | 国家市场监管总局（国标委） | GB 2760 食品添加剂使用标准 | 必须执行，违者违法            |
| 国家标准 | **GB/T**                              | 推荐性国家标准              | 推荐     | 同上                       | GB/T 40636-2021 挂面       | 自愿；被合同/法规引用即变强制 |
| 国家标准 | **GB/Z**                              | 国家标准化指导性技术文件    | 参考     | 同上                       | GB/Z ×××× 技术指南         | 不是正式标准，只作指引        |
| 国家标准 | **GSB**                               | 国家标准样品                | 实物     | 同上                       | GSB 07-× 水质标样          | 校准用，不是文本标准          |
| 行业标准 | **JB/T**                              | 机械行业                    | 多推荐   | 工信部                     | JB/T 8734 电机试验         | 无国标时补位；有国标即废      |
| 行业标准 | **NY/T**｜**YY/T**｜**HJ**｜**JG/T**… | 农业／医药器械／环保／建工… | 多推荐   | 对应部委                   | NY/T 419 绿色食品 大米     | 同上，且不得与国标冲突        |
| 地方标准 | **DB** + 行政区划码                   | 地方标准                    | 多为推荐 | 省级/市级市场监管局        | DB13/T × 河北地方标准      | 只在本行政区有效              |
| 团体标准 | **T/** + 社团代号                     | 团体标准                    | 推荐     | 学会、协会、产业联盟       | T/CITS × 中国计量测试学会  | 市场自主，靠合同与口碑        |
| 企业标准 | **Q/** + 企业代号                     | 企业产品标准                | 自我声明 | 企业自己                   | Q/XXXX 0001S-2023          | 不得低于国标行标，须平台公示  |

> 记忆口诀：**GB 是国家底线，Q 是企业自证，T 是圈子共识，DB 是地方脾气，JB 是机械行规。**

## 1. 编号怎么读：一个标准号拆四段

以 `GB/T 40636-2021` 和 `Q/JJSP 0001S-2023` 为例：

```
GB  / T    40636   - 2021
│     │      │         └─ 发布（实施）年份，判断"新不新"
│     │      └─────────── 顺序号，纯编号，不含含义
│     └────────────────── 斜杠后的性质：T=推荐 / Z=指导 / 无=强制
└──────────────────────── 代号，决定"哪一层级"
```

```
Q  /  JJSP    0001S  - 2023
│      │        │        └─ 年份
│      │        └───────── 企业内序号；末尾 S 常表示食品类
│      └────────────────── 企业代号（拼音缩写，自己备案的）
└───────────────────────── 企业标准
```

**几个高频踩坑点**
- `GB` 后面**没有** `/T` 就是强制性，别看漏那一杠。
- 强制性国标现在**不再分**"条文强制/全文强制"，一份 GB 要么整份强制，要么就改走 GB/T。
- 年份是**发布年**，不一定等于实施年。GB/T 40636-2021 是 2021-10-11 发布、**2022-05-01 才实施**。
- 老标准会看到 `LS/T`、`SB/T`、`NY` 等**行业存量标准**，很多已被 GB/T 吸收替代（如 LS/T 3212《挂面》→ GB/T 40636-2021）。

## 2. GB 与 GB/T：强制与推荐的分界线

### 2.1 什么必须做成 GB（强制）
《标准化法》第十条划了硬边界，只有这五类能定强制国标：
1. 人身健康和生命财产安全
2. 国家安全
3. 生态环境安全
4. 满足社会经济基本管理需要
5. 法律、行政法规规定强制的

**典型强制国标（生活里最常撞见）**

| 标准号              | 管什么                      | 你会在哪看到             |
| ------------------- | --------------------------- | ------------------------ |
| GB 2760             | 食品添加剂使用              | 所有预包装食品配料表背后 |
| GB 2761             | 真菌毒素限量                | 挂面、花生、玉米检测报告 |
| GB 2762             | 污染物限量（铅、镉、砷）    | 同上                     |
| GB 4806 系列        | 食品接触材料                | 保鲜盒、纸杯、吸管、锅具 |
| GB 7718             | 预包装食品标签              | 每一包零食的标签合规性   |
| GB 4706 系列        | 家用电器安全                | 电水壶、电饭煲铭牌       |
| GB 18384 / GB 38031 | 电动汽车安全 / 动力电池安全 | 新能源车公告、检测       |

### 2.2 GB/T 为什么"自愿但又必须"
GB/T 本身不强制，但有 **4 条隐性强制通道**，实操中比 GB 还常见：
1. **写进合同 / 招标技术规格书** → 对签约方立即变强制，不达标就是违约
2. **被法律法规、部门规章引用** → 借力变强制（如环保批复引用某 GB/T 检测方法）
3. **产品包装上自我声明"执行标准：GB/T ××××"** → 构成《产品质量法》下的明示担保，做不到=不合格+虚假标注
4. **认证/评奖/准入的前置条件**（绿色食品、有机、CCC 配套方法标准）

> ⚠️ 所以看到包装印 `GB/T 40636`，含义不是"厂家随便做的"，而是"厂家公开承诺按这把尺子量，市场监管可以按这把尺子罚你"。

### 2.3 GB/Z 与 GSB：两个"不是标准的标准"
- **GB/Z（指导性技术文件）**：技术尚在演化、国际刚起步、需要给行业一个"参考姿态"时用。写"宜"、"可"，不写"应"。**不能拿来判不合格。**
- **GSB（国家标准样品）**：一瓶标定的水质标样、一块色板、一份标准菌种。它是**实物参照物**，配合 GB/T 方法标准一起用——方法标准说"怎么测"，GSB 说"拿着什么对着校"。

### 3.2 JB 单独说两句
- JB = **机械行业（JiXie Bu 的历史遗留拼音）**，管的是"机器怎么造、怎么验"。
- 你会在这些地方撞见：**电机铭牌、减速机样本、泵的性能曲线、机床验收单、设备采购技术协议**。
- 例：`JB/T 8734` 系列（旋转电机试验方法）、`JB/T 5000` 系列（重型机械通用技术条件，焊接/铸钢件/装配一堆分册）。
- **有一份 GB/T 就废掉对应 JB/T**：这是《标准化法》的"就高不就低"原则。写招标文件时别把已废止的 JB/T 抄进去，会被质疑。

### 3.3 行业标准 vs 国家标准：三级优先级
```
强制 GB  >  推荐 GB/T  >  行业标准 JB/T、NY/T…
```
- 有国标就别用行标，除非行标**更细**、且国标未覆盖该具体产品。
- 行标**不得与国标抵触**，抵触部分无效。
- 同一对象既有 GB/T 又有 JB/T：优先 GB/T；JB/T 只作为**补充工艺细节**引用（例如整机按 GB/T，焊接工序按 JB/T 5000.3）。

## 4. Q 企业标准：最容易被误解的一层

### 4.1 三个真相
1. **Q/ 不是"低人一等"**。法条要求：企业标准的技术要求**必须严于**相应的国标/行标，否则没存在意义。《标准化法》第二十一条明写了这一点。
2. **Q/ 必须自我声明公开**。在**企业标准信息公共服务平台**（qybz.org.cn）公示，未公示就印在包装上 = 违规标注。
3. **Q/ 是你被追责时最直接的证据**。包装写了 Q/XXX 0001S，市场监管抽检就按这一份判你，比判 GB/T 更狠——因为这是**你自己写的承诺**。

### 4.2 编号与识别
- 格式：`Q/` + **企业代号**（拼音缩写，备案得来）+ 顺序号 + 年份
- 食品企业常见后缀：**S**（食品）、**W**（微生物）、**JG**（建工）……非强制统一，看企业自己规则
- 例：`Q/HNJF 0002S-2024` = 河南某食品公司 2024 年发布第 2 号食品企标

### 4.3 什么时候该用 Q/
| 场景                                      | 用 Q/ 合适吗       | 说明                                      |
| ----------------------------------------- | ------------------ | ----------------------------------------- |
| 产品没有对应国标/行标（新品类、跨界产品） | ✅ 必须             | 没有 Q/ 连生产许可都办不下来              |
| 想比国标更严做卖点（更低水分、更高蛋白）  | ✅ 推荐             | 写成企标并公示，宣传有底气                |
| 已有 GB 强制标准                          | ⚠️ 只能加严不能放松 | GB 2760 的添加剂限量你不能在企标里放宽    |
| 只想应付检查随便抄一份 GB/T               | ❌ 高风险           | 抄了就得做到，鉴ourced 抽检按你抄的那份打 |

## 5. T 团体标准：这几年最活跃的一层

### 5.1 它是什么
`T/` 开头，由**依法成立的学会、协会、商会、联合会、产业技术联盟**自行制定发布，报国标委备案。
例：`T/CITS 001-2023`（CITS = 中国计量测试学会）、`T/CESA ××××`（中国电子工业标准化技术协会）。

### 5.2 为什么突然火
- 2018 年新版《标准化法》**首次给团体标准法律地位**，此前是灰色地带。
- 新技术（大模型、具身智能、低空经济、固态电池）**国标追不上**，团体标准 6~12 个月就能出一份，抢话语权。
- 政府采购、招投标、团标认证（如"领跑者"）越来越认 T/。

### 5.3 怎么判断一份 T/ 值不值得信
1. **看发布团体**：全国性一级协会 > 地方小协会 > 名称可疑的"某某中心"
2. **看是否在全国团体标准信息平台（ttbz.org.cn）可查**：查不到 = 没备案 = 别采信
3. **看起草单位名单**：有没有头部企业、国家级检测机构、高校参与
4. **看有没有被引用**：被 GB/T、行标、招标文件引用过的团标，含金量陡增
5. **警惕"团标当国标卖"**：营销话术里"国家标准级""权威认证"多半是把 T/ 说成 GB

> 速判：**T/ 是圈内人定的规矩，好用但要看是谁的圈。**

## 6. DB 地方标准：地域脾气与特色产业

### 6.1 编号规则
`DB` + **两位行政区划码** + `/T` + 顺序号 - 年份
- `DB13/T ××××-2023` → **河北省**推荐性地方标准（13 = 河北）
- `DB1305/T ××××` → 河北**邢台市**地方标准（5 位码 = 市级）
- 不带 `/T` 的 DB 是强制性地方标准，**现在极少**，只留给地方特殊安全/环保需求，且必须报国务院备案

### 6.2 地方标准能管什么（边界很严）
《标准化法》第十三条：**为了满足地方自然条件、风俗习惯等特殊技术要求，可以制定地方标准。**
- ✅ 适合：地理标志产品（如 DB13/T 某某 太行山小米）、地方特色食品工艺、地方方言/文旅服务规范、区域性污染防治
- ❌ 不适合：全国流通的通用工业品（你造个螺丝钉不该有"河北版"）
- **2018 年后新立项地方标准一律为推荐性**，且**不得设置市场准入壁垒**——不能借 DB 搞地方保护，这是红线。

### 6.3 实操注意
- 地方标准**只在发布行政区内有效**，跨省供货时对方不认。
- 找到一份 DB 先查**现行/废止**状态，各省市场监管局官网都能查，别用十年前的旧版写标书。
- 河北/邢台本地做食品、建材、装备的，值得定期刷 **河北省市场监管局 → 地方标准公开栏**，很多"冀"字号特色标准会直接影响本地抽检尺度。

## 7. 冲突与优先级：到底听谁的

### 7.1 纵向效力链（从硬到软）
```
法律 > 行政法规 > 强制性国标 GB
     > 推荐性国标 GB/T
     > 行业标准 JB/T、NY/T…
     > 地方标准 DB××/T
     > 团体标准 T/
     > 企业标准 Q/
```
⚠️ 但**企业标准在被包装明示后，对"这家企业"而言效力最高**——因为这是自设的更严承诺。所以实际执法逻辑是：

> **先按包装上写的执行标准判；那份标准再与 GB 强制底线比对；两者取其严。**

### 7.2 四条实战规则
1. **强制优先**：任何层级的标准都不能突破 GB 强制条款，突破即无效+违法。
2. **就高不就低**：企标严于国标 → 按企标；国标更新更严 → 企标须在合理期限内修订，否则旧企标自动"低于国标"失效。
3. **就新不就旧**：同一编号看年份；被替代标准（标准状态="废止"）不能作为验收依据。
4. **就细不就粗**：整机按 GB/T，具体工序/零部件允许引用更细的 JB/T、T/ 作为补充，但需在技术协议里**写明"同时满足"**。

### 7.3 一张决策图（选执行标准时照着走）
```
有没有对应强制 GB？
 ├─ 有 → 必须执行；想做卖点就在 Q/ 里加严
 └─ 没有
     ├─ 有 GB/T？ → 优先采用并包装明示
     │    └─ GB/T 太粗？ → 追加 JB/T / YY/T 等行标补细节
     ├─ 只有行标？ → 用行标，同时关注是否即将升 GB/T
     ├─ 地方特色产品？ → 查 DB13/T（河北）
     ├─ 新技术无标可依？ → 找靠谱 T/ 团标，或自定 Q/ 并公示
     └─ 全都没有？ → 必须编 Q/ 并上平台公示，否则不能合法上市
```

## 8. 实战：拿到一包挂面 / 一份检测报告，30 秒读完

### 8.1 看包装"执行标准"栏
```
执行标准：GB/T 40636        ← 推荐性国标，厂家明示承诺
生产许可证：SC101xxxxxxx     ← 食品生产许可，与标准两码事
```
- 印 **GB/T 40636** → 按 2022-05-01 实施的挂面国标：水分 ≤14.5%、酸度 ≤4.0、自然断条率 ≤5.0%、熟断条率 ≤5.0%、烹调损失 ≤10.0%
- 印 **LS/T 3212** → 老行标，**已废止**，属于标注过期（可投诉）
- 印 **Q/XXXX 0001S** → 企标，去 qybz.org.cn 输企业代号，看它自己写了多严；再拿 GB 2760/2761/2762 三条强制底线兜底比对
- 印 **T/XXX** → 团标，去 ttbz.org.cn 查备案与起草单位，判断是不是"自吹型团标"

### 8.2 看检测报告"判定依据"栏
一份合格报告通常**并列 3~4 份标准**，各司其职：
| 角色       | 举例                              | 作用                     |
| ---------- | --------------------------------- | ------------------------ |
| 产品标准   | GB/T 40636 挂面                   | 判等级、判感官与理化指标 |
| 安全底线   | GB 2762 污染物 / GB 2761 真菌毒素 | 判能不能吃               |
| 添加剂依据 | GB 2760                           | 判配料合不合法           |
| 标签依据   | GB 7718                           | 判包装字写得对不对       |
| 方法标准   | GB 5009 系列 / HJ ×××             | 只管"怎么测"，不判合格   |
> 常见事故：**拿方法标准当产品标准写进合同** —— 结果验收时无指标可判，扯皮半年。

### 8.3 写招标文件 / 技术协议的三条保命写法
1. 引用标准一律带**年份**：`符合 GB/T 40636-2021`，不写"现行国标"（"现行"会随更新漂移，双方理解不一）。
2. 多标准并存时写清**关系**：`应同时满足 GB/T ×××× 与 JB/T ××××；指标不一致时以较严者为准`。
3. 明确**版本变更处理**：`合同期内标准修订发布的，自新标准实施日起按新标准执行，供方不得以旧版已报价为由加价`。

## 10. 常见误区 12 条（逐条打勾自检）

- [ ] ❌ "GB 开头都是强制的" → **带 /T 就是推荐**，别漏那一杠
- [ ] ❌ "推荐性标准可以不看" → 写进合同/印上包装就变成你的法律责任
- [ ] ❌ "企业标准比国标低，是偷工减料" → 法律要求企标**更严**；更松的企标备案不了
- [ ] ❌ "有 Q/ 就是三无/山寨" → 恰恰相反，新品类没 Q/ 无法取证上市
- [ ] ❌ "T/ 团体标准=国标" → 团标是社团自律，营销里说成"国家标准"属虚假宣传
- [ ] ❌ "DB 地方标准可以在全国用" → 只在本行政区有效，跨省不认
- [ ] ❌ "JB/T 比 GB/T 低级所以不能用" → 国标没覆盖的工艺细节，JB/T 是正当补充
- [ ] ❌ "标准号不带年份更灵活" → 不带年份=引用漂移，验收必扯皮
- [ ] ❌ "标准印在包装上就一定是现行" → 大量小厂还在印已废止的 LS/T、SB/T
- [ ] ❌ "检测报告合格=产品合规" → 报告只判了它测的那几项，标签、添加剂、许可另算
- [ ] ❌ "方法标准（GB 5009/HJ）能当验收指标" → 它只说怎么测，不说合格线
- [ ] ❌ "GB/Z 也是国标，能拿来开罚单" → 指导性文件无强制力，只能参考

## 12. 延伸：这套体系为什么会这样长出来（理解背景就不容易记混）

- **1950s–1980s**：全部是"国家标准 GB"，苏联式计划体制，一部委一套，标准=生产指令。
- **1989 年《标准化法》**：第一次分出**强制 / 推荐**，出现 GB/T；行业标准的雏形是各部颁标准（JB 从一机部而来，所以拼音不是"JiXie"的正经缩写而是历史遗留）。
- **2000 年前后**：加入 WTO，标准要对标 ISO/IEC，GB/T 大量等同采用（IDT）、修改采用（MOD）国际标准，行标爆发式增长到 50 多类。
- **2018 年新《标准化法》**（2018-01-01 施行）：结构性大改——
  - 强制标准**只留 GB 一个层级**，强制行标、强制地标逐步消化归位；
  - **首次承认团体标准**，T/ 合法化；
  - 企业标准从"备案制"改为**"自我声明公开制"**（所以才有 qybz.org.cn）；
  - 地方标准限定为"自然条件、风俗习惯等特殊技术要求"，禁止拿来做市场壁垒。
- **2023 年《国家标准管理办法》**修订：立项更强调"强制性标准底线化、推荐性标准市场化"，并明确 GB/Z、GSB 的定位。

> 理解了这条线就明白：**GB 越少越硬，GB/T 越多越软，T/ 和 Q/ 才是创新速度最快的两层。** 看一份标准先问"它出生在哪个年代、为了解决谁的焦虑"，比背代号更管用。
