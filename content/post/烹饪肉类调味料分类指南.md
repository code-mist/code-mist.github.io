# 烹饪肉类调味料分类指南（完整版）

**总口诀：焯水基本冷水下锅；炖煮加热水；煎鱼热锅热油；虾贝鱿鱼水开短焯、大火快熟；盐后放，小火慢炖。**

## 一、处理与下锅水温总表

| 肉类      | 怎么处理                               | 下锅水温                                               | 软烂/不柴关键                                   |
| --------- | -------------------------------------- | ------------------------------------------------------ | ----------------------------------------------- |
| 猪肉      | 冷水浸泡去血水；五花肉可先煸油或炒糖色 | **焯水冷水下锅**；炖煮**加热水**                       | 小火1—1.5小时；盐后放；五花肉别久煮过火         |
| 牛肉      | 冷水浸泡，**逆纹切**；草果拍破去籽     | **焯水冷水**；炖煮**加热水**                           | 加山楂/番茄/几滴醋；小火1.5—2.5小时；盐后放     |
| 羊肉      | 冷水浸泡焯水；清炖配白萝卜             | **焯水冷水**；炖煮**加热水**                           | 花椒、姜、白萝卜去膻；小火1—1.5小时；清炖少香料 |
| 鸡肉      | 洗净；炖汤可冷水下锅，鸡块先焯水       | 焯水**冷水**；炖汤**冷水下锅**更出味；炖鸡块**加热水** | 小火40—60分钟；盐最后放；香料少，姜葱为主       |
| 鸭肉      | 冷水焯水或干煸出油去臊味               | **焯水冷水**；炖煮**加热水/啤酒**                      | 先煸后炖；小火1—1.5小时；姜、蒜、啤酒去腥       |
| 鹅肉      | 同鸭，先焯水或干煸；肉较老可多炖       | **焯水冷水**；炖煮**加热水**                           | 小火1.5—2小时；姜、啤酒、少量八角；香料比鸭略重 |
| 鱼        | 去黑膜血水，擦干；煎前少抹盐           | **煎鱼热锅热油**；鱼汤煎后**加热水**，大火滚白         | 不久炖；红烧最后收汁；鱼汤先煎再加热水          |
| 虾        | 去虾线、剪须、开背；虾仁擦干           | 水煮/焯水**水开下锅**；蒸**水开上锅**；炒**热锅热油**  | **变色卷曲即熟**，别久煮；虾仁大火快炒，盐后放  |
| 贝类      | 吐沙、刷洗                             | **水开下锅**，煮至开口                                 | 开口即捞，别久煮；姜葱料酒去腥                  |
| 鱿鱼/章鱼 | 去膜、改花刀；章鱼可先拍松             | **水开焯10—20秒**；炒**大火热锅**                      | 短时快炒，久了橡皮；姜蒜去腥                    |
| 兔肉      | 冷水浸泡去血水，焯水                   | **焯水冷水**；炖煮**加热水**                           | 小火1—1.5小时；姜、花椒去腥；香料别重           |
| 鸽子/乳鸽 | 洗净焯水；炖汤可冷水下                 | **焯水冷水**；炖汤**冷水下锅**                         | 小火1—1.5小时；姜葱、枸杞，清淡为主             |
| 牛蛙      | 洗净斩块，可水开短焯                   | **水开短焯10秒**或直接热锅快炒                         | 大火快炒2—3分钟；别久煮，肉会散柴               |

## 二、各类肉调味料分类

| 肉类      | 主香料                                              | 去腥/增香                                          | 调味                                                   | 要点                                                         |
| --------- | --------------------------------------------------- | -------------------------------------------------- | ------------------------------------------------------ | ------------------------------------------------------------ |
| 猪肉      | 八角1—2颗、桂皮1小段、香叶2—3片                     | 葱段、姜片、蒜；料酒、少量醋                       | 生抽、老抽上色、冰糖/白糖                              | 猪肉本身鲜甜，香料别多，大料多了发苦发闷；五花肉必放糖色     |
| 牛肉      | 八角、桂皮、香叶、**草果1颗拍破去籽**、小茴香一小撮 | 姜片、葱段、料酒、少许白胡椒；山楂干2—3片或几滴醋  | 生抽、老抽、豆瓣酱（川味）                             | 牛肉腥味重、纤维粗，香料可比猪肉略重；加山楂或番茄帮助炖烂   |
| 羊肉      | **花椒一小把、白胡椒粒、孜然**、姜片多放            | 白萝卜同炖吸膻、料酒、白芷1小片可选                | 清炖只放姜片、花椒、盐；红焖加八角、桂皮、干辣椒、孜然 | 羊肉怕大料桂皮过重盖住鲜味，**花椒是灵魂**，清炖萝卜汤最经典 |
| 鸡肉      | 姜片、葱段，**只需1颗八角或干脆不放**               | 香菇、红枣、枸杞、料酒少许                         | 盐最后放、白胡椒                                       | 鸡肉鲜、异味轻，**香料越少越好**，大料多了反而毁鸡汤；重点在姜和火候 |
| 鸭肉      | 八角1—2颗、桂皮1小段、香叶、**草果1颗**             | 姜片大量、蒜、料酒、啤酒代替水                     | 生抽、老抽、冰糖、干辣椒                               | 鸭肉臊味重，先焯水或干煸出油脂再炖；香料比鸡重、比牛轻       |
| 鹅肉      | 姜、蒜、啤酒、少量八角桂皮                          | 同鸭去腥；可干煸出油                               | 生抽、老抽、冰糖、干辣椒可选                           | 先焯/煸，炖更久；香料略重于鸭                                |
| 鱼        | **不放花椒大料**                                    | 姜片、葱段、料酒、少许白胡椒；猪油煎鱼、香菜、香葱 | 盐、糖少许、生抽（红烧）、豆腐（鱼汤）                 | 河鱼可放极少量花椒；**海鱼和清炖鱼汤千万别放大料**，会发苦、破坏鲜味 |
| 虾        | 不放八角大料                                        | 姜、葱、蒜、料酒少许                               | 盐、白胡椒；清蒸/白灼配姜醋                            | 水开短煮，变色卷曲即熟，别久煮                               |
| 贝类      | 不放八角                                            | 姜、葱、料酒                                       | 盐少许；蒜蓉粉丝蒸或姜葱炒                             | 开口即捞，别久煮                                             |
| 鱿鱼/章鱼 | 不放八角                                            | 姜、蒜、料酒                                       | 生抽、盐                                               | 短时焯/炒，久了橡皮                                          |
| 兔肉      | 姜、花椒、少量八角                                  | 料酒                                               | 生抽、老抽、盐                                         | 香料别重，姜花椒去腥                                         |
| 鸽子/乳鸽 | 姜、葱、枸杞                                        | 料酒少许                                           | 盐、白胡椒                                             | 清淡为主，香料少                                             |
| 牛蛙      | 不放八角                                            | 姜、蒜、料酒                                       | 盐、白胡椒、生抽；可加干辣椒、花椒                     | 大火快炒，不久煮                                             |

## 三、通用口诀表：大料用量 + 灵魂香料

| 肉类       | 大料用量 | 灵魂香料  |
| ---------- | -------- | --------- |
| 猪         | 1—2颗    | 冰糖+八角 |
| 牛         | 2—3颗    | 草果+山楂 |
| 羊         | 0—1颗    | 花椒+萝卜 |
| 鸡         | 0—1颗    | 姜+香菇   |
| 鸭/鹅      | 1—2颗    | 姜+啤酒   |
| 鱼         | 不放     | 姜+葱     |
| 虾/贝/鱿鱼 | 不放     | 姜+葱/蒜  |
| 兔         | 0—1颗    | 姜+花椒   |
| 鸽         | 0—1颗    | 姜+枸杞   |
| 牛蛙       | 不放     | 姜+蒜     |

## 四、三个铁律 + 营养提醒

**三个铁律：**  
① 香料宁少勿多，多了发苦；  
② 用纱布袋装香料，炖好方便捞出；  
③ 盐别太早放，肉不易烂。

**营养提醒：**没有“营养全部吸收”这回事。建议**连汤带菜吃、肉配蔬菜**；补铁搭配维C蔬菜，少油炸、少过度久煮。

**简单执行版：**猪肉香料少、必放糖色；牛肉加草果山楂；羊肉花椒萝卜；鸡肉少香料多姜；鸭鹅姜啤酒；鱼不放八角；虾贝鱿鱼水开短焯、大火快熟；兔姜花椒；鸽清淡；牛蛙大火快炒。
