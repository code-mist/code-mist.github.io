## 一、DHCP 服务器是什么？

**DHCP（动态主机配置协议）** 服务器是路由器内置的核心服务，作用是**自动为连接到网络的设备分配 IP 地址**，省去手动配置的麻烦。

### DHCP 的核心作用

| 作用             | 说明                                           |
| :--------------- | :--------------------------------------------- |
| **自动分配 IP**  | 新设备接入时，从地址池中选一个空闲 IP 分配给它 |
| **避免 IP 冲突** | 确保每个设备的 IP 独一无二，不会互相“打架”     |
| **回收 IP 资源** | 设备断开网络后，IP 被回收供其他设备使用        |

### DHCP 设置建议

- **保持开启状态**：这是绝大多数家庭网络的标准配置
- **地址池建议**：起始 IP 设为 `100`，结束 IP 设为 `199`（如 `192.168.1.100` ~ `192.168.1.199`），避开路由器本身和静态 IP 设备
- **租约时间建议**：设为 24~72 小时（1~3 天）

## 二、VPN 协议：PPTP vs L2TP

### PPTP（点对点隧道协议）

| 特性     | 说明                                       |
| :------- | :----------------------------------------- |
| **特点** | 数据简单封装，打包速度极快                 |
| **优点** | 设置简单，几乎所有设备都支持，速度损失最小 |
| **缺点** | 安全性低，加密技术过时，易被拦截           |
| **现状** | 因不安全，很多网络已禁止使用               |

### L2TP/IPsec（二层隧道协议）

| 特性     | 说明                                           |
| :------- | :--------------------------------------------- |
| **特点** | L2TP 本身不加密，需配合 IPsec 使用（双层加密） |
| **优点** | 安全性高，加密强度远超 PPTP                    |
| **缺点** | 速度略慢于 PPTP，设置时需要填写预共享密钥      |

### 对比总结

| 对比项         | PPTP               | L2TP/IPsec       |
| :------------- | :----------------- | :--------------- |
| **安全性**     | ⭐ 低               | ⭐⭐⭐⭐ 高          |
| **传输速度**   | ⭐⭐⭐⭐⭐ 快           | ⭐⭐⭐⭐ 略慢        |
| **设置复杂度** | ⭐ 简单             | ⭐⭐⭐ 需预共享密钥 |
| **稳定性**     | 差，易被防火墙拦截 | 好，较难被拦截   |

### 建议

**日常使用优先选择 L2TP/IPsec**。PPTP 在 2010 年后已被安全界视为“不再安全”的协议。只有在 VPN 服务商明确要求时才使用 PPTP。

## 三、手机 Wi-Fi 设置详解

### 1. 代理（Proxy）

| 选项     | 含义                         | 适用场景                      |
| :------- | :--------------------------- | :---------------------------- |
| **无**   | 手机直接连接互联网           | **日常首选**                  |
| **手动** | 手动填写代理服务器 IP 和端口 | 公司/学校等需要代理的网络环境 |
| **PAC**  | 用规则文件自动配置代理       | 高级用法，一般由 IT 部门配置  |

> **建议**：保持“无”即可。

### 2. IP 设置

| 选项     | 含义                          | 适用场景                                    |
| :------- | :---------------------------- | :------------------------------------------ |
| **DHCP** | 路由器自动分配 IP             | **日常首选**，即连即用                      |
| **静态** | 手动填写 IP、子网掩码、网关等 | 打印机/NAS 需要固定 IP，或路由器关闭了 DHCP |

> **建议**：保持“DHCP”即可。

### 3. 隐私（MAC 地址）

| 选项             | 含义                 | 适用场景                                           |
| :--------------- | :------------------- | :------------------------------------------------- |
| **使用随机 MAC** | 每次连接使用虚拟身份 | **日常首选**，防止商家追踪                         |
| **使用设备 MAC** | 暴露真实的硬件地址   | 路由器设置了 MAC 地址过滤，或公司/学校需要绑定设备 |

> **建议**：日常使用“随机 MAC”即可，不影响上网速度。

### 手机 Wi-Fi 设置总结

| 选项        | 推荐设置     | 原因                   |
| :---------- | :----------- | :--------------------- |
| **代理**    | 无           | 直连最快               |
| **IP 设置** | DHCP         | 自动分配，省心不出错   |
| **隐私**    | 使用随机 MAC | 保护隐私，家用无副作用 |

## 四、路由器的四种上网模式

### 1. 宽带账号上网（PPPoE）

- **工作方式**：路由器亲自拨号上网，需输入宽带账号和密码
- **适用场景**：光猫已改为桥接模式时使用
- **改错后果**：如果光猫已拨号，会拨号失败导致断网

### 2. 自动获取 IP（DHCP）

- **工作方式**：路由器向上级设备申请 IP，自己再开独立网段
- **适用场景**：想让路由器独立管理自己的设备时
- **改错后果**：手机和光猫设备不在同一网段，投屏、打印、NAS 访问可能失效

### 3. AP 模式（接入点模式）

- **工作方式**：不分配 IP，只负责把上级网络用 Wi-Fi 放大
- **适用场景**：**家庭最优配置**，网络结构最简单稳定
- **改错后果**：改完就失去 AP 模式的简便性

### 4. 手动输入 IP（静态 IP）

- **工作方式**：手动填写 IP、子网掩码、网关等全套参数
- **适用场景**：企业专线或特殊网络环境
- **改错后果**：99% 会填错导致无法上网

### 模式选择建议

**家庭用户保持“AP 模式”是最优解**。除非你有特殊需求（如独立管理网络），否则不建议更改。

## 五、AP 模式详解

**AP（Access Point，接入点）模式**，就是把路由器从“会管事的经理”变成“只会传话的扩音器”。

### AP 模式 vs 路由模式

| 对比             | 路由模式                 | AP 模式                    |
| :--------------- | :----------------------- | :------------------------- |
| **角色**         | 独立的“小老板”           | 听话的“传话筒”             |
| **分配 IP**      | 自己说了算               | 完全听从上级设备           |
| **设备网段**     | 独立网段                 | 与上级设备同一网段         |
| **VPN/端口转发** | 可自己设置，但受上级限制 | 基本不需要设置，全交给上级 |

### 为什么 AP 模式下 VPN 设置在路由器上无效？

因为 AP 模式下的路由器只负责转发数据，不参与任何“网络决策”。所有 VPN、端口转发、DMZ 等设置，都必须在**上级设备（如光猫）**上操作。

## 六、什么是“二级路由器”？

**二级路由器**是指不直接连接光猫，而是插在另一台路由器下面的路由器。

### 如何判断上级是不是光猫？

看 WAN 口 IP 地址：
- 如果 WAN IP 是 `192.168.1.x`，说明上级设备 IP 是 `192.168.1.1`
- 光猫默认 IP 通常是 `192.168.1.1`，所以上级极大概率是光猫

**判断方法**：
1. 拔掉路由器的 WAN 口网线
2. 用设备连光猫自带的 Wi-Fi（或直接用网线插光猫）
3. 看获取到的 IP 是否也是 `192.168.1.x`
4. 如果是，说明上级就是光猫

## 七、光猫配置详解

### 7.1 光猫的上网连接设置

| 参数         | 示例值                  | 含义                                                   |
| :----------- | :---------------------- | :----------------------------------------------------- |
| **上网连接** | `2_INTERNET_R_VID_1420` | 上网通道配置文件，`R` 代表路由模式，`VID` 是 VLAN 标签 |
| **端口绑定** | LAN1~LAN4、SSID1、SSID2 | 这条通道对哪些接口开放                                 |
| **模式选择** | 拨号连接（PPPoE）       | 光猫自己在拨号上网                                     |
| **用户名**   | 宽带账号                | 运营商给的拨号账号                                     |
| **MRU**      | 1492                    | 数据包最大大小，PPPoE 标准值                           |

### 7.2 光猫的 Wi-Fi 设置

| 参数                 | 建议         | 说明                               |
| :------------------- | :----------- | :--------------------------------- |
| **Wi-Fi 总开关**     | ON           | 总闸门                             |
| **无线名称（SSID）** | 自定义       | Wi-Fi 名字                         |
| **隐藏网络**         | 不勾选       | 勾选后搜不到，需手动输入 SSID 连接 |
| **安全模式**         | WPA/WPA2-PSK | 兼容性最好                         |
| **无线信道**         | 自动         | 路由器自动选择最通畅的频道         |
| **工作模式**         | Mixed        | 兼容所有设备（b/g/n 混合）         |
| **无线功率**         | 最大覆盖     | 信号强度最大                       |

### 7.3 端口绑定详解

在光猫的上网连接设置中，端口绑定决定了**这条上网通道允许哪些接口使用**：

| 选项            | 含义                                      |
| :-------------- | :---------------------------------------- |
| **LAN1~LAN4**   | 光猫背后的有线网口                        |
| **2.4G(SSID1)** | 第一个 2.4G Wi-Fi（如 `CMCC-Jin`）        |
| **2.4G(SSID2)** | 第二个 2.4G Wi-Fi（如 `CMCC-GUIDE-LINK`） |

> **注意**：这里的勾只控制“该接口能否通过这条通道上网”，不是“该 Wi-Fi 是否存在”。

### 7.4 访客网络设置

| 参数         | 含义           | 建议                       |
| :----------- | :------------- | :------------------------- |
| **SSID**     | Wi-Fi 名称     | 可自定义，方便识别         |
| **工作时间** | Wi-Fi 定时开关 | 无特殊需求保持“全天”或留空 |

> **访客网络的作用**：给客人独立密码，与主网络隔离，保护主网络安全。

### 7.5 光猫的 IPv6 设置

| 参数                 | 示例值 | 含义                   |
| :------------------- | :----- | :--------------------- |
| **全局地址获取方式** | SLAAC  | 设备自己生成 IPv6 地址 |
| **网关获取方式**     | 自适应 | 自动获取 IPv6 网关     |
| **DNS 获取方式**     | 自适应 | 自动获取 IPv6 DNS      |
| **前缀获取方式**     | DHCPv6 | 从运营商获取地址段     |

这些设置解释了为什么手机连 Wi-Fi 后会显示 IPv6 地址（如 `fe80::...` 或 `240e:...`）。



## 八、光猫自带 Wi-Fi 信号问题

### 8.1 光猫的 SSID1~SSID4

光猫可以同时发射多个不同名称的 2.4G Wi-Fi 信号：

| SSID            | 典型用途                                |
| :-------------- | :-------------------------------------- |
| **SSID1**       | 家庭主网络                              |
| **SSID2~SSID4** | 访客网络、IPTV 专用网络、智能家居网络等 |

多 SSID 的核心价值在于：**可以给不同信号分配完全不同的权限和用途**，实现网络隔离。

### 8.2 关于 `CMCC-GUIDE-LINK` 信号

这是一个中国移动光猫自带的**引导热点**（Guide-Link），用于智能家居设备自动发现并连接家庭 Wi-Fi。

| 特征     | 说明                                     |
| :------- | :--------------------------------------- |
| **用途** | 帮助智能音箱、灯泡等设备配网             |
| **密码** | 通常无密码，或使用设备内置密码（不公开） |
| **风险** | 低风险，信号仅用于配网，不直接通主网络   |

**关闭方法**：
- 目前普通用户界面下找不到关闭此信号的选项
- 可通过“和家亲”APP 解绑光猫，信号可能消失
- 最稳妥方法：拨打 10086 或联系装维师傅从后台关闭

## 九、最终结论：我家网络的真实结构

### 设备清单

| 设备           | 型号        | IP 地址            | 角色                            |
| :------------- | :---------- | :----------------- | :------------------------------ |
| **光猫**       | GM220-S     | `192.168.1.1`      | 主路由器（拨号 + DHCP + Wi-Fi） |
| **无线路由器** | 华为 TC7001 | WAN: `192.168.1.2` | AP 模式（Wi-Fi 信号扩展器）     |
| **手机**       | -           | `192.168.1.8`      | 终端设备，由光猫分配 IP         |

### 网络拓扑图

```
互联网
   │
   ▼
┌─────────────┐
│   光猫      │  ← 主路由器（拨号上网、DHCP 服务器）
│ GM220-S     │  ← IP: 192.168.1.1
│ 路由模式    │  ← 发射 Wi-Fi: CMCC-Jin、CMCC-GUIDE-LINK
└──────┬──────┘
       │
       │ 网线
       ▼
┌─────────────┐
│ 华为 TC7001 │  ← AP 模式（纯 Wi-Fi 扩展器）
│ WAN IP:     │  ← IP: 192.168.1.2
│ 192.168.1.2 │  ← 发射 Wi-Fi: 华为的 Wi-Fi 信号
└─────────────┘
```

### 关键结论

1. **光猫就是主路由器**：负责拨号上网、DHCP 分配 IP、所有网络决策
2. **华为 TC7001 只是“传话筒”**：工作在 AP 模式，只负责放大 Wi-Fi 信号
3. **所有设备在同一网段**：`192.168.1.x`，互相可以访问（投屏、打印、NAS 都通）
4. **任何高级设置（VPN/端口转发）都必须在光猫上操作**，在华为路由器上设置无效


## 十、光猫的端口绑定：上网通道与接口的关系

在光猫的上网连接设置页面（2_INTERNET_R_VID_1420），有一组“端口绑定”选项：

| 选项 | 含义 |
| :--- | :--- |
| **LAN1 ~ LAN4** | 光猫背后的4个有线网口 |
| **2.4G(SSID1)** | 第一个2.4G Wi-Fi信号（如 `CMCC-Jin`） |
| **2.4G(SSID2)** | 第二个2.4G Wi-Fi信号（如 `CMCC-GUIDE-LINK`） |

**关键理解**：这里的勾选，控制的是“该接口是否允许通过这条上网通道上网”，而不是“该接口是否存在”。

- 如果取消勾选 `2.4G(SSID2)`，连上 `CMCC-GUIDE-LINK` 的设备无法上网，但信号本身依然存在。
- 要彻底关闭一个Wi-Fi信号，需要去Wi-Fi设置页面找单独的“开启/关闭”开关，或者“隐藏网络”选项。

**结论**：端口绑定是“权限控制”，不是“开关”。


## 十一、关于 `CMCC-GUIDE-LINK` 信号

### 11.1 它是什么？

`CMCC-GUIDE-LINK` 是中国移动光猫自带的**引导热点**（Guide-Link），用于智能家居设备自动发现并连接家庭Wi-Fi。

| 特征 | 说明 |
| :--- | :--- |
| **用途** | 帮助智能音箱、灯泡等设备配网，实现无感连接 |
| **密码** | 通常无密码，或使用设备内置密码（不公开） |
| **风险** | 低风险，仅用于配网，不直接通主网络 |

### 11.2 如何关闭？

普通用户界面下**找不到关闭此信号的选项**。可行的办法有：

1. **通过“和家亲”APP解绑光猫**：登录APP，在设备管理中解绑光猫，信号可能消失。
2. **联系运营商**：拨打10086或联系装维师傅，从后台关闭。
3. **复位+切换地区**：有用户反馈，复位初始设置后切换地区，信号会消失（但会重置所有配置）。

**不建议**：刷机或修改固件，风险极高。

## 十三、家庭网络带宽分析

### 13.1 网络拓扑

```
互联网 → 光猫（路由模式）→ 华为TC7001（AP模式）→ Wi-Fi → 手机/电脑
                                    ↘ 网线 → 摄像头
```

### 13.2 各环节带宽能力

| 环节 | 设备/介质 | 理论最大带宽 | 对300M宽带的影响 |
| :--- | :--- | :--- | :--- |
| 运营商线路 | 光纤 | 1000M+ | ✅ 无影响 |
| 光猫处理 | GM220-S | 千兆 | ✅ 无影响 |
| 网线 | 超五类及以上 | 1000M | ✅ 无影响 |
| 华为TC7001 WAN口 | 千兆网口 | 1000M | ✅ 无影响 |
| **2.4G Wi-Fi** | 路由器发射 | 实际50~100Mbps | ⚠️ **最大瓶颈** |
| **5G Wi-Fi** | 路由器发射 | 实际300~500Mbps | ✅ 能跑满300M |

### 13.3 摄像头占用

家用1080P摄像头上传码率约 **2~8Mbps**，占300M宽带的 **不足3%**，可忽略不计。

### 13.4 测速建议

- **有线测速**：电脑网线直插光猫LAN3/LAN4口，测速接近300M说明运营商正常。
- **无线测速**：手机连接 **5G Wi-Fi**，在路由器旁边测速，应达到250~300M。
- **如果只能跑50~80M**：说明连的是2.4G频段，切换到5G即可。


## 十四、腾达旧路由器的接入方案

### 14.1 当前状态

腾达路由器通过网线连接华为TC7001，WAN口获取IP `192.168.1.15`，LAN口自己开网段 `192.168.0.1`，形成 **三级网络**。

### 14.2 问题

| 问题 | 影响 |
| :--- | :--- |
| 多层NAT | 延迟增加，打游戏Ping值偏高 |
| 设备不在同一网段 | 投屏、打印、NAS访问失效 |
| 端口转发复杂 | 需在两层路由器都做映射 |

### 14.3 解决方案：改AP模式

将腾达从“路由模式”改为“AP模式”的完整操作：

1. **拔掉WAN口网线**（让WAN口“失业”，固件不再限制LAN口网段）
2. **修改LAN口IP**：从 `192.168.0.1` 改为 `192.168.1.250`（与光猫同网段，不冲突）
3. **关闭DHCP服务器**
4. **物理插拔**：将网线从WAN口拔出，**插入任意LAN口**

**完成后的效果**：
- 腾达变为“纯AP”，所有设备在 `192.168.1.x` 网段
- 投屏、打印、NAS访问全部恢复
- WAN口彻底闲置（废弃）

**为什么不能直接改？**：腾达固件禁止WAN口和LAN口在同一网段。必须先拔掉WAN口网线，让WAN口处于“未连接”状态，才能修改LAN口IP。


## 十五、无线中继模式

### 15.1 腾达的两种中继模式

| 模式 | 工作方式 | 对网络的影响 | 推荐 |
| :--- | :--- | :--- | :--- |
| **WISP（热点信号放大）** | 连上级Wi-Fi，自己开独立网段 | 设备不在同一网段，投屏失效 | ❌ |
| **Client+AP（万能中继）** | 连上级Wi-Fi，与上级同一网段 | 设备在同一网段，所有功能正常 | ✅ |

### 15.2 中继后的IP访问

中继成功后，腾达的管理IP由上级路由器（华为/光猫）的DHCP分配，**手动设置的IP可能不生效**。

| 管理界面 | 访问方式 |
| :--- | :--- |
| **光猫** | `192.168.1.1` |
| **华为TC7001** | `192.168.11.1`（AP模式保留独立管理IP） |
| **腾达** | `tendawifi.com` 或 上级分配的动态IP |

**如何查看腾达真实IP**：
- 在腾达后台“LAN口设置”中查看
- 在华为路由器的“已连接设备”列表中根据MAC地址查找
- 在手机Wi-Fi详情中查看“网关”地址

### 15.3 中继后主路由Wi-Fi连不上的问题

**现象**：腾达中继成功，`tenda_JIN` 能上网，但原来的华为Wi-Fi（`JIN`）连不上了。

**原因排查**：
1. **白名单/接入控制**：华为路由器开启了MAC地址过滤，只允许特定设备连接 → 把手机MAC加入白名单，或关闭过滤
2. **双频合一**：华为开启了2.4G和5G同名 → 关闭双频合一，中继只连2.4G
3. **IP冲突**：两个DHCP服务器冲突 → 关闭腾达DHCP
4. **信号干扰**：两个Wi-Fi同信道 → 固定华为的信道为1/6/11

### 15.4 中继后UPnP自动禁用

在“万能中继（Client+AP）”模式下，腾达路由器为保持稳定性和兼容性，会自动关闭UPnP等高级功能。这是正常现象，不影响中继功能本身。


## 十六、操作失误案例：白名单模式

**场景**：在华为路由器管理页面误将Wi-Fi设置成“白名单模式”，只允许腾达路由器的MAC地址连接。

**结果**：
- 腾达中继成功（因为它的MAC在白名单里）
- 手机/电脑能看到 `JIN` 信号，但永远连不上（MAC不在白名单里）

**解决办法**：
1. 手机连 `tenda_JIN`（还能上网）
2. 登录华为后台（`192.168.11.1`）
3. 找到MAC地址过滤/接入控制，**关闭白名单**，或**添加手机MAC到白名单**
4. 保存后恢复正常


## 十七、光猫与路由器的正确摆放位置

### 17.1 光猫

| 原则 | 说明 |
| :--- | :--- |
| 不要塞进弱电箱铁壳 | 铁皮屏蔽信号，散热也差 |
| 保持竖立 | 散热更好，减少死机 |
| 光纤线不能弯折90度 | 自然盘绕即可 |

### 17.2 华为TC7001（主AP）

| 原则 | 具体做法 | 原因 |
| :--- | :--- | :--- |
| **居中** | 放在房子几何中心（如客厅电视柜） | 信号向四周均匀辐射 |
| **高处** | 离地1.5~2米 | Wi-Fi向下辐射更好 |
| **开阔** | 周围无遮挡 | 墙壁、金属会衰减信号 |
| **远离金属** | 远离金属机箱、铁皮柜 | 金属反射和吸收Wi-Fi |
| **远离电器** | 离微波炉、蓝牙音箱2米以上 | 避免2.4G频段干扰 |

### 17.3 腾达（无线中继）—— 关键！

**核心法则：中继不能放在信号盲区里！**

- ❌ 错误：卧室没信号 → 把腾达放卧室
- ✅ 正确：把腾达放在**华为路由器 和 信号盲区 的中间位置**

**摆放要点**：
- 插在墙壁高处插座（不要放地上）
- 天线竖直向上，与华为天线平行
- 华为和腾达之间不要隔超过一堵承重墙

**信号判断**：用手机在腾达位置看华为Wi-Fi信号，**2~3格**是理想位置。
