## 一、六种食材的下锅注意事项

### 1. 排骨
- **焯水要冷水下锅**：冷水和肉一起升温，血水杂质才能慢慢渗出；热水下锅会让表面蛋白质瞬间凝固，血沫锁在肉里，汤会腥。
- 焯完用**温水冲洗**，别用冷水激，否则肉质收紧发柴。
- 炖汤**一次加足水**，中途加水汤会变寡、肉变硬。
- **盐最后放**：早放盐会让肉里的水分提前渗出，肉柴汤也不鲜。
- 炖煮全程小火，大火猛炖肉会散、口感发柴。

### 2. 菠菜
- **必须焯水**：菠菜草酸含量高，直接炒会涩嘴，还影响钙吸收。沸水下锅，30秒～1分钟即可。
- 焯水时加少许盐和油，颜色更翠绿；捞出沥干再炒。
- **不要久炒久煮**，软烂发黄既难看也损失营养。
- 炒的时候**出锅前再放盐**，先放盐会大量出水。

### 3. 虾
- **去虾线**：影响口感和卫生，牙签从背部第二节挑出即可。
- 白灼虾**水开后再下锅**，加姜片、料酒去腥；虾身一变红卷曲就捞出，多煮一分钟都会老。
- 炒虾要**热锅热油、大火快炒**，下锅前擦干水分防溅油。
- 想要嫩滑可以上薄浆（少许淀粉+蛋清），但虾本身易熟，别过度腌制。

### 4. 青菜（叶菜类）
- **大火快炒**，全程不要盖锅盖，焖会发黄出水。
- **先炒梗、后放叶**：梗比叶难熟，一起下锅叶子烂了梗还生。
- **盐最后放**，先放盐菜会"杀出水"，变成一锅汤泡菜。
- 如果要焯水（做拌菜等），沸水加盐加油，几秒就捞出过凉。

### 5. 豆角（含四季豆、芸豆、扁豆）— 这条最重要
- **必须彻底做熟**：生豆角含皂素和植物血凝素，没熟透会引起中毒，症状是恶心、呕吐、腹泻，严重需就医。这是家庭厨房最常见的食物中毒来源之一。
- **不能图脆嫩急火短炒出锅**。正确做法是：先焯水（沸水至少3～5分钟）或下锅后加少许水**焖煮到完全变色、质地变软、没有生豆腥味**。
- 判断标准：颜色从鲜绿变成暗绿/黄绿色，尝不出生味。中火焖炒通常需要8分钟以上。
- 用豆角做馅（包子、饺子）更要先焯透再剁。

### 6. 莲藕
- 切好立刻**泡在加了白醋的清水里**，防止氧化变黑；用铁锅切或炒也会发黑，尽量用不锈钢锅或砂锅。
- **分清脆藕和粉藕**：脆藕（九孔藕）适合清炒、凉拌、滑炒；粉藕（七孔藕）适合煲汤炖煮，选错口感会差很多。
- 炒藕要**大火快炒**，沿锅边淋一点白醋，脆爽洁白。
- 炖汤选粉藕切大块，冷水下锅与排骨同炖，盐同样后放。

## 二、容易出错的食材清单

| 食材                   | 常见错误           | 正确做法                                                     |
| ---------------------- | ------------------ | ------------------------------------------------------------ |
| **豆角、四季豆**       | 急炒断生就出锅     | 彻底焖熟/焯透，无生味才安全                                  |
| **鲜黄花菜（金针菜）** | 直接鲜炒           | 含秋水仙碱，需摘除花蕊、焯水、清水浸泡2小时以上；建议用干黄花菜 |
| **干木耳、银耳**       | 温水久泡、隔夜泡发 | 泡发时间过长会滋生米酵菌酸（可致命），温水1～2小时、冷水不超过4小时，泡好即用，勿隔夜 |
| **发芽/变绿的土豆**    | 只挖掉芽眼就炒     | 龙葵素遍布变绿部分，发芽严重直接丢弃；轻度发芽要削厚皮、加醋烹调 |
| **豆浆**               | 煮到冒泡就喝       | "假沸"现象，皂苷未分解，需沸腾后再持续煮5～10分钟            |
| **菠菜、苋菜、竹笋**   | 不焯水直接炒       | 草酸高，沸水焯30秒以上去涩、防结石风险                       |
| **鸡蛋（溏心蛋）**     | 追求流心           | 未全熟的蛋有沙门氏菌风险，老人、小孩、孕妇尤其要全熟         |
| **禽肉（鸡鸭）**       | 带血丝就出锅       | 必须全熟，中心温度达标，无血水                               |
| **白果（银杏）**       | 当零食多吃         | 含银杏酸，成人一次不超过10颗，必须煮熟                       |
| **苦杏仁**             | 生食               | 含氰苷，需彻底加热，且不宜多吃                               |
| **木薯、生豆浆类**     | 处理不当           | 含氰苷类物质，去皮、浸泡、煮透                               |
| **海鲜/河鲜**          | 不新鲜也下锅       | 只要不新鲜立即弃用；死贝类（蛏子、花蛤）开口不闭的要扔掉     |
| **隔夜绿叶菜**         | 觉得可惜继续吃     | 亚硝酸盐升高，尤其室温放置的，尽量现做现吃                   |
| **蘑菇**               | 采食野生蘑菇       | 无法凭经验鉴别，一律不采不买不食不明野生菌                   |
| **肉类冷水/热水混用**  | 焯水用热水         | 肉类焯水一律冷水下锅；蔬菜焯水一律沸水下锅，这是最容易搞混的一条 |

---

**总结成一句口诀**：肉冷锅、菜热锅，豆角焖透别图脆，菠菜笋类先焯水，木耳泡发别过夜，发芽土豆直接扔。
