# 旧手机当摄像头笔记

> 目标：旧手机安装软件后当监控摄像头，尽量降低 CPU 消耗，同时保证录像质量。  
> 推荐软件：**Android IP Camera**（F-Droid / GitHub 可下载，免费开源）。  
> 备选：IP Webcam。

## 1. 安装与权限

- 从 F-Droid 或 GitHub Releases 下载 **Android IP Camera**
- 授予 **相机、麦克风、存储、后台运行** 权限
- 设置用户名和密码，开启 HTTPS
- MIUI 省电策略设为 **无限制**，允许自启动和后台活动

## 2. 启动与访问

1. 打开 App，点击 **Start Server**
2. 记住显示的地址，通常是：

```text
https://手机IP:4444
```

3. 电脑浏览器访问该地址，首次提示证书不安全，点“继续前往”
4. 实时流地址通常是：

```text
https://手机IP:4444/video/mjpeg
```

如果切换 H.264：

```text
https://手机IP:4444/video/h264
```

## 3. 降低 CPU 消耗的设置

| 项目   | 推荐值       | 说明                       |
| ------ | ------------ | -------------------------- |
| 分辨率 | 720p 或 480p | 1080p 会明显增加发热和耗电 |
| 帧率   | 10–15 FPS    | 监控不需要高帧率           |
| 编码   | H.264        | 比 MJPEG 省 CPU 和带宽     |
| 屏幕   | 关闭屏幕推流 | App 内开启选项             |
| 电池   | 充电上限 80% | 长期插电建议开启电池保护   |
| 后台   | 无限制       | 防止被 MIUI 杀掉           |

## 4. 录像质量与存储

- 录像质量跟随分辨率、帧率设置
- 想更清晰：720p + 15 FPS
- 想更省电：480p + 10 FPS
- 建议把保存路径改为：

```text
/storage/emulated/0/Download/IPCamera
```

原因：Termux 可以直接访问，避免 `Android/data` 权限问题。

## 5. 回看与文件管理

两种方式：

1. **直接用 App 的 Web 界面回看**
2. **用 Termux 文件管理器浏览录像目录**

Termux 文件管理器根目录改为：

```python
BASE_DIR = '/storage/emulated/0/Download/IPCamera'
```

然后启动 Flask 文件服务器，电脑浏览器访问 `http://手机IP:5000`，即可浏览、下载、删除录像。

## 6. 外网访问

推荐 **Tailscale**：

- 手机和电脑都安装 Tailscale
- 登录同一账号
- 外网访问：

```text
https://100.x.x.x:4444
```

不用改 Android IP Camera 的任何配置。

## 7. 常见问题

- **画面卡顿**：降低分辨率、帧率，改用 H.264
- **无法访问**：确认同一 Wi-Fi、手机 IP 是否正确、App 是否在运行
- **后台被杀**：MIUI 设为无限制，锁定后台，关闭省电模式
- **找不到录像文件**：在 App 设置里查看保存路径，或运行：

```bash
find /storage/emulated/0 -name "*.mp4" -mmin -10 2>/dev/null
```

- **不想自己写监控服务**：直接用 App 的 Web 界面即可，Termux 只负责文件管理

## 8. 推荐组合

```text
Android IP Camera  → 负责视频流、录像、拍照
Termux 文件管理器  → 负责浏览、下载、删除录像
Tailscale          → 负责外网访问
```

监控交给专门 App，文件管理交给 Termux，外网交给 Tailscale。
