# 记录一次 Windows 里 WiFi 突然“消失”的排查经历

前几天打开电脑，右下角的 WiFi 图标不见了。点开网络面板，只剩飞行模式和有线网络相关选项，无线网络列表完全空白。第一反应是“是不是网卡坏了”，但冷静下来想了想，WiFi 消失这事儿，绝大多数时候还是软件、服务或驱动层面的问题。于是按从简单到复杂的顺序排查了一遍，最后恢复了。这篇博客就当作一次记录，也给以后遇到同样情况的自己留个备忘。

## 一、先别急着重装系统

WiFi 图标消失，不等于无线网卡一定坏了。先判断问题大概在哪一层：

- 是飞行模式或物理开关被误触？
- 是 Windows 的无线服务没运行？
- 是设备管理器里网卡被禁用或驱动异常？
- 还是系统网络组件出了问题？
- 最后才考虑 BIOS 设置或硬件故障。

按照这个顺序查，比一上来就重装系统或乱装驱动软件要稳得多。

## 二、先检查最容易被忽略的开关

我先看了任务栏右下角的网络图标，确认没有误开**飞行模式**。飞行模式会直接禁用无线通信，WiFi 列表和选项都可能消失。

然后检查了笔记本的物理开关和功能键。有些机型有独立的 WiFi 开关，或者需要通过 `Fn + F2`、`Fn + F4` 之类的组合键开启无线功能。如果被误触关闭，Windows 里也会看不到 WiFi。

这一步虽然简单，但确实值得先做，因为排查成本最低。

## 三、检查 WLAN AutoConfig 服务

Windows 管理无线网络的核心服务是 **WLAN AutoConfig**。如果它意外停止，WiFi 功能就会失灵。

我按 `Win + R`，输入 `services.msc` 打开服务列表，找到 **WLAN AutoConfig**。这次发现它的状态不太对，启动类型也不是“自动”。我把它重新启动，并把启动类型设为“自动”。

不过重启服务后，WiFi 图标还是没有立刻回来，说明问题不止这一层。

## 四、设备管理器里找到了线索

接着右键“开始”按钮，打开“**设备管理器**”，展开“**网络适配器**”。

这里有几个常见情况：

- 无线网卡图标上有**向下箭头**：说明被禁用了，右键“启用设备”即可；
- 无线网卡带**黄色感叹号**：通常是驱动异常；
- “网络适配器”下完全找不到无线网卡：可以点“查看” > “显示隐藏的设备”再看看。

我这次的情况是：无线网卡还在，但带有黄色感叹号。基本可以判断是驱动层面出了问题。

## 五、卸载驱动后重启

处理驱动问题时，我没有直接去下载第三方驱动软件，而是先在设备管理器里右键那个带感叹号的无线网卡，选择“**卸载设备**”。注意，我没有勾选“删除此设备的驱动程序软件”，然后重启电脑，让 Windows 自动重新识别并安装驱动。

重启后，WiFi 图标恢复了一部分，但网络列表仍然不太稳定。于是我又做了下一步：网络重置。

## 六、网络重置与命令修复

Windows 自带的“网络重置”很好用。路径是：

“**设置**” > “**网络和 Internet**” > “**高级网络设置**” > “**网络重置**”，然后点击“立即重置”，系统会提示重启。

除此之外，我还以管理员身份打开了命令提示符，依次执行了下面几条命令：

```cmd
netsh winsock reset
netsh int ip reset
ipconfig /flushdns
```

这几条命令分别用于重置网络协议栈、重置 IP 配置和清除 DNS 缓存。执行完后再次重启电脑。

另外也顺手运行了系统文件检查：

```cmd
sfc /SCANNOW
```

这一步不是每次都必须做，但如果怀疑系统文件受损，可以作为补充排查。

## 七、最后确认 BIOS 和硬件状态

做到这里，WiFi 已经基本恢复正常。为了保险，我又进 BIOS 看了一眼无线相关选项，确认无线网卡没有被禁用。不同主板选项名称不一样，常见的有 **Wireless**、**WLAN**、**Network**、**Onboard Devices** 等，确保相关设备处于 Enabled 状态。

如果所有软件方法都试过，无线网卡在设备管理器和 BIOS 里依然完全不见踪影，那就要考虑硬件问题了。这种情况下，比较实际的方案是先用一个 **USB 无线网卡**临时替代，再联系售后或维修人员检测内置网卡和主板相关电路。

## 八、这次问题的结论

这次最终排查下来，问题主要是**无线网卡驱动异常，加上 WLAN AutoConfig 服务状态不对**。通过重启服务、卸载异常驱动、重启让系统重装驱动，再配合网络重置和命令修复，WiFi 功能恢复了正常。

虽然过程不算特别复杂，但中间确实容易让人烦躁。总结下来，最有效的思路就是：**先查开关和服务，再看设备管理器，最后做网络重置和驱动重装，仍然无效再考虑 BIOS 和硬件。**

## 九、给以后的自己留一份排查清单

以后 Windows 里 WiFi 再消失，我会按这个顺序来：

1. 检查飞行模式是否被误开；
2. 检查笔记本物理开关和 `Fn` 功能键；
3. 打开 `services.msc`，确认 **WLAN AutoConfig** 正在运行且启动类型为自动；
4. 打开设备管理器，查看无线网卡是否被禁用、是否有黄色感叹号；
5. 卸载异常无线网卡驱动，重启让 Windows 自动重装；
6. 执行“网络重置”；
7. 以管理员身份运行 `netsh winsock reset`、`netsh int ip reset`、`ipconfig /flushdns`；
8. 必要时运行 `sfc /SCANNOW`；
9. 去电脑品牌或主板官网手动下载安装无线网卡驱动；
10. 进 BIOS 确认无线网卡未被禁用；
11. 做一次硬件断电重置；
12. 如果仍然完全找不到无线网卡，考虑 USB 无线网卡临时替代并送修检测。

## 后记

WiFi 突然消失，看起来像是硬件坏了，但实际排查下来，很多问题都能在 Windows 的服务、驱动和网络组件里找到原因。这次经历也提醒我，遇到问题先别急着重装系统，按层次一步步排查，反而更快。
