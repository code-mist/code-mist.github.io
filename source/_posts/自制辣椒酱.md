# 自制辣椒酱 🌶️
## 所需食材
### 主料
| 食材   | 用量            |
| ------ | --------------- |
| 红辣椒 | 1000克（约2斤） |
| 大蒜   | 150克           |
| 生姜   | 50克            |
### 调料
| 调料           | 用量    |
| -------------- | ------- |
| 食用油         | 200毫升 |
| 盐             | 40克    |
| 白糖           | 30克    |
| 白酒（高度）   | 30毫升  |
| 豆瓣酱（可选） | 2汤匙   |
| 十三香/五香粉  | 1茶匙   |
---
## 制作步骤
### 第一步：处理辣椒
1. 辣椒洗净后**彻底晾干水分**（这一步很关键，有生水容易变质）
2. 去蒂，剁碎或用料理机打碎（喜欢有颗粒感的可以剁碎）
### 第二步：准备配料
1. 大蒜去皮剁成蒜末
2. 生姜去皮剁成姜末
### 第三步：炒制辣椒酱

1. 锅中倒油，放入花椒、八角
2. 小火炸至香料变色出香后**捞出弃掉**
3. 油温降至五成热

1. 先放入姜末、蒜末，小火炒出香味（约2分钟）
2. 倒入辣椒碎，转**中小火**慢慢熬炒
3. 熬炒过程中不停搅拌，防止糊锅（约15-20分钟）
4. 待辣椒水分蒸发，油色变红亮时，加入盐、糖、十三香
5. 最后淋入白酒，搅拌均匀后关火

### 第四步：装瓶保存
1. 玻璃瓶提前**用开水烫过并晾干**
2. 辣椒酱放凉后装入瓶中
3. 表面可淋一层食用油封口
4. 冷藏保存，可存放**1-3个月**
---
## 小贴士 💡
- ⚠️ **全程无生水**：所有器具和食材都不能沾生水，这是保存长久的关键
- 🌶️ 辣度选择：小米辣（特辣）、二荆条（中辣微香）、菜椒（不辣）可按口味混搭
- 🍶 加白酒既能防腐又能增香
- 👐 切辣椒时建议戴手套，避免辣手
- ❄️ 取用时用干净的勺子，能延长保存时间
